# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short
- Be welcoming, respectful and constructive.
- Focus on what is best for the community and the project.
- Harassment, insults, discriminatory language and personal attacks are not tolerated.

## Enforcement
Instances of unacceptable behavior may be reported to the maintainer through a
[private security advisory](https://github.com/crisbraatz/metaphone-pt-br/security/advisories/new)
or by contacting the maintainer via their GitHub profile. All reports will be reviewed promptly
and handled confidentially. The maintainer may remove, edit or reject contributions, or ban
contributors, for behavior that violates this code of conduct.
